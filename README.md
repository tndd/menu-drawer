# MenuDrawer — Typelessのアイコン表示切り替え

v0.6.0は、Typelessのメニューバーアイコンを表示／非表示にする小さなMacアプリです。以前の収納・画像ドロップダウン方式を廃止しました。採用済みのガラスの引き出しアイコンは維持しています。

## 使い方

`/Applications/MenuDrawer.app`を起動し、メニューバーの引き出しを押します。

- 「非表示にして起動／再起動」で、Typelessを動かしたままアイコンを消します。
- 「表示して起動／再起動」で、アイコンを戻します。
- 上部に現在の表示状態が出ます。処理中は切り替え操作とMenuDrawerの終了を無効にします。

切り替え時にはTypelessを正常終了して起動し直すため、音声入力を終了してから操作してください。Typelessを別途終了・再起動すると、アイコンの表示が戻ることがあります。その場合は再度「非表示にして再起動」を選びます。

画面収録・アクセシビリティの許可は不要です。画像取得、画面外へのアイコン移動、カーソル移動、キー入力の送信は行いません。旧版の権限がmacOSの設定に残っていても使用しません。アプリのインストール先は一つだけです。

## 実装と制約

Typeless 2.8.2（Electron 33.4.11）で、`now.typeless.desktop`の`NSStatusItem Visible Item-0`を終了後に書き、再起動する方式を検証しています。この設定名は公開APIではないため、TypelessやmacOSの更新後も効くとは保証しません。

起動後は、保存設定とWindowServerのウィンドウ情報（所有PID・メニューバー層・画面上の有無）で表示状態を確認します。画面の画像やウィンドウの内容は取得しません。非表示は起動後に連続して観測し、起動直後にアイコンがまだない状態を成功と判定しないようにしています。

強制終了は行いません。終了が拒否された場合は設定を書き換えません。設定変更・起動・表示確認が失敗した場合は、元の設定値（未設定ならキーを削除）と元の起動状態へ戻します。復旧にも失敗した場合は、そのことをエラーに表示します。

対応対象はTypelessだけです。ログイン時の自動処理、更新の監視、音声入力の操作、ほかのアプリのアイコン管理は行いません。

## ビルドと確認

```sh
scripts/build.sh
scripts/test.sh
scripts/test.sh --live
```

ビルド成果物は`build/MenuDrawer.zip`です。組み立て用の一時的なアプリはビルド終了時に削除します。通常テストは切り替え手順と失敗時の復旧を検証します。

`--live`はインストール済みMenuDrawerの実メニューをアクセシビリティ経由で操作し、Typelessの非表示／表示を各2回確認します。検証後は元のTypelessの設定・起動状態へ戻します。このテスト用プロセスには操作用のアクセシビリティ権限が必要ですが、製品本体には必要ありません。Macのロック解除と、Typelessの音声入力停止が必要です。
