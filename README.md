# メニュードロワー

選んだステータスアイコンだけを収納し、引き出しボタンから**本物のアイコン画像をメニューバーの下へ表示する**Macアプリです。v0.5.0では、通常のアプリアイコンと名前の一覧を廃止し、実アイコンを並べたドロップダウンに変更しました。

## 使い方

`/Applications/MenuDrawer.app` を開き、アクセシビリティと画面収録を許可します。

1. 設定で収納したい項目にチェックし、「選択を保存」を押します。未選択の項目はメニューバーに残ります。
2. 引き出しボタンを押すと、選んだ実アイコンが下に並びます。クリックすると元のメニューや画面を開きます。メニューを閉じると再収納します。
3. 一つだけ取り出すには、ドロップダウンの外へアイコンをドラッグします。設定でチェックを外して保存する方法でも取り出せます。元の隣接項目を記録して、元の並びへ戻します。
4. 引き出しボタンの右クリックで設定を開きます。設定を開くだけでは収納を解除しません。選択は次回起動にも保存します。終了したアプリの選択も設定から解除できます。

設定の「すべて戻す」は全選択の解除です。収納が空になると、内部の区切り項目を完全に取り除きます。終了時もネイティブの並びを復元し、区切りを撤去します。時計とコントロールセンターの固定項目は常時表示します。ログイン時の自動起動やコントロールセンター拡張は含めていません。

## 権限と仕組み

アクセシビリティはアイコンの識別・移動・元の機能の操作に、画面収録は実アイコンの画像取得に使います。画面収録が滑らかさを保証するわけではありません。移動の見え方は別の処理で抑えています。

他アプリの既存のNSStatusItemを別のパネルへ直接移設する公開APIはありません。このアプリは対象を一時的に引き出しの隣へ移動して本物をクリックし、元のメニューを操作します。その間はメニューバー右側の固定画像で配置の変化を隠し、再収納後に固定画像を撤去します。固定画像はマウス操作を遮りません。メニューが開いている間、その範囲の表示更新も一時的に止まります。

画像はステータス項目とメニューバーの必要範囲だけを取得し、メモリで扱います。通常起動での画像保存、録画、ネット送信は行いません。画面収録を解除しても、アクセシビリティがあれば設定から項目を取り出せます。

画面外のステータス項目は従来のCGWindow画像APIで取得します。現行SDKでは非推奨のため、Cの橋渡しをmacOS 14ターゲットでビルドしています。移動イベントには公開名のないフィールド番号51も使用します。将来のmacOS変更に影響される可能性があります。AXから一意に識別できる項目が対象です。元の隣接項目が終了していた場合は、生きている最寄りの項目を基準に戻します。全アプリ・全ディスプレイ・全画面モードは網羅していません。

## アイコン

採用したB案のガラスの引き出しを静的な`.icns`へ書き出しました。1024pxまでの複数解像度と透明な外周を持ちます。メニューバーでは同じ形を18ptの単色テンプレート画像にし、明暗の色付けをmacOSに任せています。Appleの[アプリアイコン指針](https://developer.apple.com/design/human-interface-guidelines/app-icons)に沿う形式ですが、Appleの認証を受けたものではありません。ガラスの質感は画像に描かれたものです。

`Resources/MenuDrawer.icns`はアプリ実行時に必要な採用デザインの入力資産としてGit管理します。検証画像は管理対象外の`build/tests/`へ保存します。

## ビルドと検証

Apple Silicon、macOS 14以降、Xcode Command Line Toolsでビルドします。外部パッケージは使用しません。

```sh
scripts/build.sh
scripts/test.sh
scripts/test.sh --integration
scripts/test.sh --real
```

ビルド結果は`build/MenuDrawer.zip`です。アプリの組み立ては一時フォルダで行い、ビルド終了時に削除します。通常配置するアプリ本体は`/Applications/MenuDrawer.app`一つに統一し、インストール版を自動で上書きしません。UI検証は、両方の権限を許可して通常起動した`/Applications/MenuDrawer.app`へ実際のクリック・ドラッグを送ります。検証前に設定の選択を空にしてください。検証側の端末にもアクセシビリティが必要です。

- `--integration`: 本物の別プロセスのアイコンを取得・移動・クリック。ドロップダウンからメニューと通常画面を開く二つの経路、再収納、実ドラッグで元の順序へ復帰、空の収納の区切り撤去を確認します。
- `--real`: ChatGPT・バッテリー・入力メニュー・Wi‑Fiを個別に選び、未選択項目の表示、元の機能、再収納、二項目の同時表示と操作、片方だけの解除、元の順序への復帰を確認します。メニュー内の機能は選びません。最後に検証用の選択を解除します。

`--validation-output <PNGの絶対パス>`を付けた検証起動だけは、アプリのビュー、ドロップダウン周辺、固定前と操作中のメニューバー範囲をPNGへ保存します。通常起動は保存しません。検証では画像を目視し、ビューを描けたことと、画面上で表示・操作できたことを分けて確認します。

ローカル用のアドホック署名です。再ビルドで署名が変わると、設定がオンでも許可が通らない場合があります。その場合は旧MenuDrawerを両方の権限一覧から削除し、現在の`/Applications/MenuDrawer.app`を追加し直します。画面収録の設定が求めた場合はアプリを再起動してください。
