# MenuDrawer — 選んだメニューバーアイコンを収納

v0.8.0の実装候補。以前のアプリ固有設定の上書き方式を廃止し、Iceの選択移動・収納の仕組みに基づいて作り直しています。現時点の完了条件と保留事項は[VALIDATION.md](VALIDATION.md)に記載しています。

## 操作

メニューバーの引き出しを押すと、現在の実アイコンの一覧が出ます。

- 項目を選ぶと、そのアイコンだけを収納します。収納中はチェックが付きます。
- チェックを外すと、元の隣接アイコンを基準に表示側へ戻します。
- 「全て取り出す」で収納を解除します。収納が空になると、境界用のステータス項目自体を撤去します。
- 通常終了ではアイコンを戻し、次回の起動時に保存済みの選択を再適用します。

アプリの再起動や、対象アプリの設定値の書き換えは行いません。収納・取り出しはアイコンごとの操作です。同じアプリに複数のアイコンがある場合も、個別のウィンドウを対象にします。

## 権限と署名

アイコンの移動にはアクセシビリティが必要です。画面収録は不要です。画像取得、画像の複製表示、収納アイコンの代理クリックは行いません。

設定画面は、ユーザーがメニューの「アクセシビリティを許可…」を選択した場合だけ開きます。起動時、切り替え時、失敗時に設定画面へ自動遷移する処理はありません。OSの権限要求ダイアログを自動で出す処理もありません。

旧版では仮署名を用いており、コードの版ごとに識別条件が変わりました。今後は `MenuDrawer Local Signing` の固定証明書を使います。秘密鍵はキーチェーンに保存し、ビルド時だけmacOS標準の `/usr/bin/codesign` が使用します。製品の通常動作では署名鍵を使用しません。

初期準備の認証は別々です。

1. 証明書をコード署名用途として信頼する設定の承認。
2. `codesign`がその秘密鍵を利用する承認。OSの鍵利用ダイアログで、この専用鍵について`codesign`を「常に許可」した場合に継続利用できます。
3. アプリがメニューバー項目を移動するための初回アクセシビリティ許可。

証明書の信頼だけでは秘密鍵の利用やアクセシビリティまで許可されません。設定画面や署名確認を作業側から繰り返し開く運用は止めています。固定署名での更新後の許可保持は、実際に確認してから完了扱いにします。

## 収納の仕組み

Iceのコミット `11edd39115f3f43a83ae114b5348df6a0e1741cf` を調査しました。詳細とライセンスは[THIRD_PARTY.md](THIRD_PARTY.md)に記載しています。

メニューバーの実ウィンドウを列挙し、対象のウィンドウIDを指定したCommandドラッグ相当の操作で、収納境界の左へ移動します。境界を広げて選んだアイコンを画面外へ退避させます。追加収納・個別取り出しでは境界全体を展開しないため、既に収納した別アイコンを一斉に再表示しません。

移動イベントはPIDとセッションの両経路で到達を確認し、移動後の位置も検査します。マウス操作や修飾キー入力中は移動を開始しません。カーソル位置を保存し、移動中は非表示にし、成功・失敗の両方でボタン解放と位置の復元を行います。

アプリの起動・終了、ディスプレイ変更の通知時に状態を照合します。新規に左端へ追加された未選択アイコンを、収納側に置いたままにしない処理を含みます。

## 制約

- 時計、コントロールセンター本体、Siri、録画・録音などの保護表示は、IceにもあるmacOS側の制約に従います。アプリ固有の表示設定がないことを理由に、通常アプリを一括で非対応扱いにする方式ではありません。
- アプリをまたいでアイコンを移動する公開APIはなく、Iceと同様にWindowServerの非公開API・イベントフィールドを使用します。検証環境はmacOS 15.8.1、Apple Silicon。別のOS版での動作は未検証です。
- 選択の保存は、単一アイコンならアプリID、複数なら一意の識別子を用います。識別子がない複数アイコンも実行中は個別に操作できますが、再起動後に別アイコンを推測して選択しません。
- 強制終了時は非同期の位置復元を実行できません。境界自体はプロセス終了で消えますが、元の並びの保証は通常終了を対象にします。
- マルチディスプレイ、フルスクリーン、画面接続変更後の全経路は未検証です。

## ビルド・配置・検証

```sh
scripts/test.sh
scripts/test.sh --native
scripts/test.sh --real
scripts/build.sh
scripts/install.sh
scripts/test.sh --live
```

`--native`は一時的な検証アプリ2個の収納・取り出しと、3個目の新規起動を検査します。検証後にアプリ・設定・登録を片付けます。`--real`はChatGPTと入力メニューの実アイコンを、同じ収納エンジンを使う独立した検証プロセスから操作して元へ戻します。`--live`はインストール済みアプリの実メニューを操作します。いずれもMacのロック解除が必要です。これらの確認は相互の代用にはしません。

`build.sh`は固定署名がない場合、通常ビルドを中止します。成果物は `build/MenuDrawer.zip` です。署名が失敗した場合は新しいZIPを書き出しません。`install.sh`は署名の検証を済ませてから起動中アプリを終了し、`/Applications/MenuDrawer.app`の一つだけへ配置します。仮署名版を通常インストールすることは拒否します。

専用証明書の初期作成スクリプトは `scripts/create_signing_identity.sh` です。キーチェーンへ鍵とコード署名用の信頼設定を追加するため、ユーザーの明示承認を得た場合にのみ実行します。既に同名の証明書がある場合は重複作成しません。
