# メニュードロワー

メニューバーのトレイボタンを押すと、収納したアイコンをメニューバーの**下**に表示する小さなMacアプリです。1行5個で下方向へ折り返し、数が多い場合はスクロールします。パネル内のアイコンを選ぶと、元アプリのメニューを開きます。

## 起動

`build/MenuDrawer.app` を開いてください。現時点の動作検証環境は Apple Silicon / macOS 15.8.1 です。

1. 設定画面の「権限を設定」を押し、macOSの設定で **MenuDrawer** のアクセシビリティと画面収録を許可します。画面収録の許可後はアプリを再起動してください。
2. ⌘キーを押しながら、収納したいアイコンをメニューバーの「│」より左へ移動します。「│」自体はトレイボタンの左に配置してください。右側のアイコンは常時表示されます。
3. 「収納を開始」を押します。トレイボタンでパネルを開閉できます。パネル外のクリック、Escでも閉じます。
4. 配置の変更や終了は、トレイボタンを右クリックします。「終了して元に戻す」で収納を解除して終了します。

macOSが移動を許可しない時計などの固定項目は、そのまま表示します。自動起動は設定しません。

## 権限の用途

- **画面収録**：各メニューバーアイコンのウィンドウ画像を取得し、パネルへ表示します。画像はメモリ上で使い、画面全体の録画、ファイル保存、ネット送信は行いません。
- **アクセシビリティ**：選んだアイコンを特定し、そのメニューを開きます。

権限がないときは収納しません。画像が取得できない項目は「?」表示になります。対象を一意に特定できない場合やアプリがメニュー操作に対応しない場合はエラーを表示し、別の項目を推測で操作しません。

## ビルドと検証

Xcode Command Line Tools の Swift / clang だけを使用します。外部パッケージへの依存はありません。

```sh
scripts/build.sh
scripts/test.sh
scripts/test.sh --integration
```

統合検証は検証専用の別プロセスを起動し、そのアイコンを収納してからアクセシビリティ経由で元のメニューを開き、実際のメニューウィンドウが出たことを確認します。実行する端末のアクセシビリティ権限が必要です。検証プロセスは終了時に停止します。通常起動中のMenuDrawerは終了してから実行してください。

```sh
build/MenuDrawer.app/Contents/MacOS/MenuDrawer --preview /絶対パス/preview.png
```

プレビューはサンプルのシステム画像を使い、実際と同じパネルの描画コードで画像を書き出します。実際のメニューバーの取得確認とは別です。

## 実装上の境界

Swift + AppKitで新規実装しています。収納には幅の大きい `NSStatusItem`、操作には `AXUIElementPerformAction` を使用します。収納中のアイコン画像取得は従来の公開API `CGWindowListCreateImage` をC側に隔離して使用しています。このAPIは非推奨であり、将来のmacOSでは置き換えが必要になる可能性があります。

ローカル用のアドホック署名です。配布用のApple公証は行っていません。再ビルドやアプリの移動により権限の再許可が必要になる場合があります。
